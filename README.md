# Unified AI Agent for Automating Tasks Across Google Workspace

## 📌 Overview

Unified AI Agent is an intelligent system that automates tasks across Google Workspace applications such as Gmail, Google Drive, Google Calendar, and Google Docs. It uses Artificial Intelligence, Natural Language Processing (NLP), and Large Language Models (LLMs) to understand user commands and execute tasks efficiently.

## 🚀 Features

* Natural Language Command Processing
* Email Automation (Send, Draft, Attach Files)
* Meeting Scheduling (Google Calendar)
* File Management (Google Drive)
* Document Creation & Summarization
* Cross-Application Workflow Automation
* Smart Task Planning using AI

## 🧠 Tech Stack

* Python
* Flask
* MongoDB
* Google Workspace APIs
* Cohere API (LLM)
* NLP (NLTK, spaCy)

## 🏗️ System Architecture

The system follows a modular architecture:

* User Interaction Layer
* NLP Processing Layer
* AI Reasoning & Task Planning
* Task Execution Layer
* Integration Layer (Google APIs)

## ⚙️ Installation

```bash
git clone https://github.com/your-username/Google-Workspace-Agent.git
cd Google-Workspace-Agent
pip install -r requirements.txt
python app.py
```

## 🔐 Environment Variables

Create a `.env` file:

```env
COHERE_API_KEY=your_api_key
MONGO_URI=your_mongodb_uri
```
